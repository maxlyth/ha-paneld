ha-paneld — F-Droid repository

ha-paneld is an open-source Home Assistant agent for Android wall panels. This is its self-hosted F-Droid repository.

Add this repo in F-Droid

In the F-Droid app: Settings → Repositories → +, then enter:

https://fdroid.ha-paneld.com/fdroid/repo?fingerprint=@FINGERPRINT@

Then install ha-paneld and receive updates directly on the panel — no PC or adb needed.

Only full releases are published here; pre-releases (…-rcN) are not. Some panel features require root — see the README.
