ha-paneld F-Droid repository (retired)

This repository is no longer updated. It could only install the app, not connect a panel to Home Assistant, so it has been replaced by Panel Assistant, the Home Assistant integration that installs ha-paneld and connects the panel once its own setup is done.

What to do instead

Add Panel Assistant to Home Assistant and give it the panel's address. Home Assistant installs the app over the network and connects the panel once its setup is done, so no computer is needed at the panel. If the panel cannot be reached over the network, Panel Assistant can also install over USB from a browser.

If you already added this repository

Nothing on your panel stops working, and the versions published here stay available. You will not receive new versions from this repository, so remove it from the F-Droid client and update the panel from Home Assistant instead.

Source and releases remain at github.com/maxlyth/ha-paneld.
