How it works

The root helper daemon bridges the dashboard WebView's debug socket (webview_devtools_remote_<pid>) to a loopback port. ha-paneld connects over CDP and runs a tiny probe (requestAnimationFrame for FPS/jank + a PerformanceObserver for long tasks) via Runtime.evaluate, then publishes the numbers here and (optionally) as HA sensors. The raw DevTools inspector link stays available for power users, but this card is the everyday view. Verdict thresholds: Smooth <5% jank · Occasional 5–15% · Janky >15%. Needs WebView debugging enabled on the dashboard app (a one-time per-panel toggle).
